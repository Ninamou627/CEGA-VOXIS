Ce que Windows va vous dire

« Windows a protégé votre ordinateur » apparaîtra au lancement de l'installateur, avec la mention éditeur inconnu.

C'est normal : cette application n'est pas encore signée par un certificat commercial. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Pour vous assurer que le fichier est bien celui que nous avons publié, comparez son empreinte avec celle affichée ci-dessus. Dans PowerShell :

Get-FileHash .\CEGA_VOXIS_Setup.exe -Algorithm SHA256

Installation

  1. Lancez le fichier téléchargé et laissez-vous guider. Aucun droit administrateur n'est nécessaire.
  2. Un raccourci est créé sur le bureau et dans le menu Démarrer.
  3. Au premier lancement, connectez-vous avec votre compte, ou saisissez le code formateur qui vous a été remis.

Mises à jour

Rien à refaire : les interfaces sont servies en ligne et se mettent à jour d'elles-mêmes. L'application ne se met à jour que rarement, en arrière-plan, et jamais pendant une séance — elle attend que vous la fermiez.

Désinstaller

Paramètres → Applications → CEGA Voxis → Désinstaller.
